# M1 兼容性实测检查单（宿主机执行）

> 目标：用边界用例假库实测 Jellyfin 10.11.11 与 Emby 4.9.5 的解析行为，
> **冻结命名规范**（docs/ARCHITECTURE.md §4，决策 D-027）。
> 本检查单只验证"扫描/识别/字幕拾取"，**不验证播放**（假媒体文件不可播放，
> 点开播放报错属预期）。

---

## 1. 前置条件

- 宿主机已安装 podman；已有 jellyfin 10.11.11 与 emby 4.9.5 镜像
  （没有的话：`podman pull docker.io/jellyfin/jellyfin:10.11.11`，
  emby 用你现有的 4.9.5 镜像）。
- 仓库内已有 `bin/fixturegen`（agent 已构建的静态二进制；若缺失，
  在仓库目录执行 `nix develop --command go build -o bin/fixturegen ./cmd/fixturegen`）。

## 2. 生成假库

```bash
cd /data/projects/hinnyuu/roxy
mkdir -p test_share
./bin/fixturegen -out test_share/library
```

预期输出 37 个文件的清单，结构为：

```
test_share/library/
├── tv/
│   ├── Test Show Alpha (2024)/        Season 00 + Season 01 + Extras + 根目录 -trailer
│   ├── Test Show Beta ~Special Edition~ (2023)/   Specials 目录（对照 Season 00）
│   └── 测试番剧Ω＆Δ (2025)/            中文 + 特殊字符（Ω、全角＆、Δ、「」）
└── movies/
    └── Test Movie 剧场版 (2025)/
```

## 3. 零写入基线快照（扫描前执行）

```bash
cd /data/projects/hinnyuu/roxy
find test_share/library | sort > /tmp/m1-before.txt
find test_share/library -type f -print0 | sort -z | xargs -0 md5sum > /tmp/m1-before.md5
```

> 注意：路径含空格，必须用 `-print0 | sort -z | xargs -0`（NUL 分隔），
> 禁止裸用 `$(find …)` 命令替换（会被 shell 按空格拆词）。

## 4. Jellyfin 测试

### 4.1 启动容器

```bash
podman volume create roxy-jf-config
podman run -d --name roxy-jellyfin \
  -p 127.0.0.1:8096:8096 \
  -v roxy-jf-config:/config \
  -v /data/projects/hinnyuu/roxy/test_share:/media:ro \
  docker.io/jellyfin/jellyfin:10.11.11
```

SELinux 报权限错误时把 `:ro` 改为 `:ro,z`。

### 4.2 初始化与建库（关键：禁用一切在线刮削）

1. 浏览器打开 `http://127.0.0.1:8096`，完成初始向导。
2. 添加媒体库：**类型=节目(Shows)**，文件夹 `/media/library/tv`。
3. 进入该库设置（…→管理媒体库→编辑），逐项确认：
   - 元数据读取器：只保留 **Nfo**（其余取消）；
   - 元数据下载器：**全部取消**（TheMovieDb、The Open Movie Database 等）；
   - 图片获取器：只保留本地来源（"从媒体文件夹"），取消所有在线源；
   - **"将图片保存到媒体文件夹"= 关闭**；
   - 内容元数据自动刷新 = 从不（或仅扫描）。
4. 再建一个库：**类型=电影(Movies)**，文件夹 `/media/library/movies`，
   同样禁用刮削。
5. 扫描媒体库（设置→活动→扫描，或建库时自动扫描）。

> 界面措辞随版本可能略有差异，按语义对齐即可；拿不准的选项记录下来反馈。
