# M2 宿主机测试检查单：扫描与规则解析（用户执行）

> 目标：验证 M2 交付物在真实环境可用——源扫描、规则解析、审核队列、
> Bangumi 本地索引（Archive dump），并回填 dump 实际体积与导入耗时。
> 本阶段**不验证**媒体服务器行为（M4）。

---

## 1. 前置条件

- 宿主机已安装 podman（或选择 §2b 二进制直跑）。
- 最近一次 main 推送的 CI 为绿，`ghcr.io/hinnyuu/roxy:dev` 可拉取
  （ROADMAP"当前进度"节已确认；镜像拉取失败时先反馈）。
- 磁盘：dump zip 约 435MB + SQLite 索引 1–2GB（DATA_DIR 所在卷）。

## 2a. 镜像方式（主路径）

```bash
cd /data/projects/hinnyuu/roxy
podman pull ghcr.io/hinnyuu/roxy:dev
deployments/podman/test-up.sh            # SELinux 环境加 --selinux
```

打开 `http://127.0.0.1:8080`，用 `admin` / `admin` 登录。

## 2b. 二进制直跑（快速迭代备选）

```bash
cd /data/projects/hinnyuu/roxy
nix build                                # 或等 agent 交付新二进制
mkdir -p test_share/downloads test_share/library
ROXY_DATA_DIR=$PWD/data ROXY_MEDIA_LIBRARY_ROOT=$PWD/test_share/library \
  ./result/bin/roxy serve
```

添加源时路径填宿主机绝对路径
`/data/projects/hinnyuu/roxy/test_share/downloads`。
