## 1. 生成探针库

```bash
cd /data/projects/hinnyuu/roxy
mkdir -p test_share
./bin/fixturegen -probe -out test_share/library
```

| E01 | 变体 A：" - "分隔组名 | `S01E01 - 第01话 - AlphaSub.mkv` / `… - BetaSub.mkv` |

## 2. 启动 Jellyfin（全新配置卷，避免旧库残留）

```bash
podman volume create roxy-jf-probe-config
podman run -d --name roxy-jf-probe \
  -p 127.0.0.1:8096:8096 \
  -v roxy-jf-probe-config:/config \
  -v /data/projects/hinnyuu/roxy/test_share:/media:ro \
  docker.io/jellyfin/jellyfin:10.11.11
```

建库同 m1.md §4.2（类型=节目，`/media/library/tv`，禁刮削只留 Nfo），扫描。

